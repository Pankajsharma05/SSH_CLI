# Keyboard shortcuts

`⌘` is Command on macOS and Ctrl on Linux. The in-app list is always available
with `?` or the **?** button.

## Everywhere

| Keys | Action |
|---|---|
| `⌘K` | Command palette — every action and host, fuzzy-matched |
| `⌘1` / `⌘2` / `⌘3` | Layout: files · files + terminal · full terminal panel |
| `Ctrl+\`` | Toggle the full terminal panel |
| `⌘T` | New terminal on the active pane's host |
| `⌘W` | Close the active terminal / editor / viewer tab |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Next / previous tab |
| `Alt+1…9` | Jump to tab *n* |
| `⌘+` / `⌘−` / `⌘0` | Terminal & editor font size |
| `?` or `F1` | Keyboard help |
| `Esc` | Close dialogs, menus, palette; cancel a drag |

## Files

| Keys | Action |
|---|---|
| `↑` `↓` | Move the cursor |
| `Shift+↑` `Shift+↓` | Extend the selection |
| `PgUp` `PgDn` `Home` `End` | Move faster |
| `↵` | Open folder · edit file · view image |
| `→` | Enter the folder under the cursor |
| `←` or `⌫` | Parent folder (cursor lands on the folder you left) |
| `Space` | Toggle selection of the current row |
| type letters | Jump to the matching name |
| `Tab` | Switch the active pane |
| `⌘A` | Select all |
| `⌘R` | Refresh |
| `⌘L` | Edit the path |
| `⌘H` | Home directory |
| `⌘D` | Bookmark this folder |
| `F2` | Rename |
| `F5` | Copy the selection to the other pane |
| `F7` | New folder |
| `Del` | Delete the selection |
| drag | Copy to the other pane (drop on a folder to go inside) |
| right-click | Context menu — everything the toolbar has, and more |

## Terminal

| Keys | Action |
|---|---|
| `Ctrl+Shift+C` | Copy the selection |
| `Ctrl+Shift+V` | Paste |
| `⌘F` | Search the scrollback |
| `Ctrl+Shift+K` / `T` / `W` / `F` | Palette · new terminal · close tab · search, *from inside a terminal* |
| middle-click a tab | Close it |
| right-click a tab | Duplicate · rename · copy all output · clear · close others |
| right-click the terminal | Copy · paste · search · clear · arm plots · full panel |

Inside a terminal, every other `Ctrl+…` chord belongs to the shell — `Ctrl+C`,
`Ctrl+L`, `Ctrl+W`, `Ctrl+K` and friends are passed straight through.

## Editor

| Keys | Action |
|---|---|
| `⌘S` | Save (writes back over the SSH connection) |
| `⌘W` | Close the tab (asks if there are unsaved changes) |
| `⌘F` | CodeMirror's own search |
